# Trellox

Trellox es una aplicación móvil de agenda para Android. Permite iniciar sesión y crear tus tareas y actividades del día a día.

## Estado del proyecto

En desarrollo. Por ahora solo está hecho el diseño de las pantallas: <br>
Diseño y Código: 
- [X] Pantalla de bienvenida
    - La pantalla de bienvenida nos muestra: El logo de la aplicación con el titulo, y un botón "Iniciar Sesión", el cual, nos llevara al login de la app.
- [X] Pantalla de inicio de sesión
    - Inicio de sesión: Titulo de la página, una imagen(user), dos input de usuario y contraseña, label "¿Hasn olvidado tu contraseña?" y dos botones uno de iniciar y otro de Registro.(No funcionan-> contraseña olvidada, ni registro)
- [ ] Pantalla principal
    - Pantalla Principal: Logo y titulo parte superior izquierda y Bienvenida + Nombre usuario en la parte superior derecha. El calendario y dos botones: uno de crear tareas y otro de mostrar dichas tareas. 
- [ ] Pantalla de creación de tareas
    - Crear Tareas: Logo y titulo parte superior izquierda, tutulo de la paginas, calendario completo, un textArea para escribir o definir la tarea y un botón de crear tarea.
- [ ] Pantalla de mostrar de tareas
    - Mostrar tareas:  Logo y titulo parte superior izquierda, flecha en la parte superior derecha para volver a la pagina principal, titulo de la pagina y se muestra la lista de tareas, las cuales se van a poder modificar y borrar.
## Tecnologías

- Android Studio
- Java
- XML (diseño de las pantallas)
